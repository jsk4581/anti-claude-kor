# anti-claude-kor

AI가 쓴 한국어 글에서 기계 티 나는 수사 패턴을 찾아내고 걷어내는 Claude Code
스킬입니다.

"결론적으로"로 여는 맺음말, `~가 아니라 ~입니다` 식의 부정 선행 정의, 항목이 늘
셋인 목록, "떠받치고 있습니다" 같은 번역투 어휘, 가운뎃점(·) 열거, `~하면 끝`
프레이밍처럼 읽다 보면 출처를 짐작하게 되는 표현들이 있습니다. 이 스킬은 그런
패턴 21종과 정황 신호 3종을 정규식 린터로 세어 슬롭 지수(0\~100)를 매기고,
허용치를 넘은 패턴만 골라 평범한 서술로 되돌립니다.

핵심 설계는 밀도 제어입니다. 개별 패턴은 전부 멀쩡한 카피라이팅 기법이므로 표현
자체를 금지하지 않습니다. 패턴마다 문서당 허용 횟수를 두고, 넘은 만큼만 벌점을
쌓습니다. 잘 쓴 대구 하나는 글을 살린다는 전제로, 장치가 눈에 띄지 않을 만큼
드문 상태를 목표로 합니다.

## 이 도구가 하지 않는 것

작성자 판별 도구가 아닙니다. 지수는 특정 어휘·구조 묶음과 얼마나 닮았는지를 나타낼
뿐이며, 사람이 AI 글을 읽으며 그 어휘를 따라 쓰게 된 경우도 같은 점수를 받습니다.
남의 글을 AI 작성이라고 지목하는 데 쓰지 말고, 자기 글에서 습관을 걷어내는 데
쓰십시오.

## 설치

skills 폴더의 내용물을 Claude Code 스킬 경로에 복사합니다.

```bash
git clone https://github.com/jsk4581/anti-claude-kor.git
cp -r anti-claude-kor/skills/* ~/.claude/skills/
```

특정 프로젝트에서만 쓰려면 `~/.claude/skills` 대신 그 프로젝트의
`.claude/skills`에 넣습니다. 새 세션부터 스킬이 등록됩니다.

## 사용

Claude Code 세션 안에서 호출합니다. `/ack`는 `/anti-claude-kor`의 줄임입니다.

```
/ack 초안.md            # 검사 후 정제, 초안.refined.md 저장
/ack 검사만: 초안.md    # 슬롭 지수 리포트만
```

파일 경로 대신 글을 붙여 넣어도 됩니다. 린터는 의존성이 없어서 단독으로도
돌아갑니다.

```bash
python3 skills/anti-claude-kor/scripts/lint.py 글.md [--json]
```

코드 블록, 인라인 코드, 블록쿼트, frontmatter는 검사에서 제외됩니다. 문제 표현을
예시로 보여주고 싶으면 코드 스팬이나 인용 블록에 넣으면 됩니다.

## 저장할 때마다 검사하기

Claude Code가 마크다운 파일을 쓰거나 고칠 때마다 슬롭 지수를 재고, 임계를 넘으면
모델에게 바로 알려 주는 훅입니다. `~/.claude/settings.json`에 추가합니다.

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          {
            "type": "command",
            "command": "python3 ~/.claude/skills/anti-claude-kor/scripts/hook-lint.py"
          }
        ]
      }
    ]
  }
}
```

임계는 기본 20이고 환경변수 `ANTI_CLAUDE_KOR_THRESHOLD`로 바꿉니다. 나중에 몰아서
고치면 이미 배포된 뒤인 경우가 많아서, 검사는 저장 시점에 거는 편이 낫습니다.

## 슬롭 지수 읽는 법

| 지수 | 해석 |
|---|---|
| 20 미만 | 정제 불필요 |
| 20\~40 | 의심 구간 |
| 40 이상 | 뚜렷한 AI체 |

참고 측정값으로, 사람이 쓴 위키백과 문서는 2 안팎, AI가 쓴 마케팅 카피는
87\~99가 나왔습니다. 300자 미만의 짧은 글에서는 밀도 기반 지수의 신뢰도가
낮습니다.

## 어떤 패턴을 잡나

구조(부정 선행 정의, 3항 강박, 정정 접속 상투구, 무노력 프레이밍 등), 기호와
서식(가운뎃점, 화살표, 이모지 불릿, 굵은 글씨 남용), 어휘(공간 은유 "자리/판/틈",
번역투 에이전트 어휘, 단순 동사 회피 "~로 기능합니다"), 담화(맺음말 상투구) 네
층위 21종입니다. 전각 대시, 어미 통일, 쉼표 비율 세 가지는 사람 글에도 흔해서
정황 신호로만 다루며, 다른 패턴이 허용치를 넘었을 때만 가산합니다. 전체 목록과
예문, 예외, 근거는 [REFERENCE.md](skills/anti-claude-kor/REFERENCE.md)에 있습니다.

패턴에는 등록 시기가 붙어 있습니다. AI 유행어는 해마다 바뀌므로 목록은 낡고, 새
표현이 보이면 추가하고 낡은 항목은 내립니다.

대구와 스타카토 리듬은 정규식으로 잡히지 않아서, 정제 단계에서 모델이 육안으로
함께 줄이도록 지침에 포함해 두었습니다.

## 재작성 검증 루프

정제를 수행하는 것도 결국 같은 모델이라, 고치면서 같은 패턴을 다시 흘려 넣기
쉽습니다. 그래서 스킬은 재작성본을 반드시 린터로 재검증하고, 지수가 20을 넘으면
남은 항목을 다시 고치게 되어 있습니다. 린터가 재작성자를 감시하는 구조입니다. 같은
모델은 자기 습관을 잘 못 보므로, 정제본을 다른 모델에 한 번 더 검토시키면 남은
표현이 더 잡힙니다.
