# anti-claude-kor

클로드가 쓴 한국어에는 티가 납니다. `A가 아니라 B입니다`로 시작하는 정의, 문단
끝마다 붙는 `결론적으로`, 항목이 꼭 셋인 목록, `떠받치고 있습니다` 같은 번역투.
이 플러그인은 그런 표현이 글에 얼마나 몰려 있는지 세어 점수를 매기고, 많이 나온
것만 골라 평범한 문장으로 고칩니다.

표현 하나하나를 금지하지는 않습니다. 어느 것이든 한두 번은 괜찮은 기법이고, 문제는
같은 장치가 문단마다 되풀이될 때 생깁니다. 그래서 패턴마다 허용 횟수를 두고, 넘긴
만큼만 점수에 반영합니다.

## 설치

Claude Code에서 아래 두 줄을 차례로 입력합니다.

```
/plugin marketplace add jsk4581/anti-claude-kor
/plugin install anti-claude-kor@anti-claude-kor
```

설치하면 세 가지가 함께 들어옵니다.

- 정제 스킬 `/anti-claude-kor:anti-claude-kor`. 줄여서 `/anti-claude-kor:ack`
- 검사 스크립트. 파이썬 3만 있으면 단독으로도 돌아갑니다
- 저장 훅. 마크다운 파일을 쓰거나 고칠 때마다 점수를 재고, 20을 넘으면 Claude에게
  고치라고 알립니다

플러그인 없이 스킬 폴더만 복사해 써도 됩니다. 이렇게 넣으면 `/ack`로 바로 부를 수
있고, 저장 훅은 빠집니다.

```bash
git clone https://github.com/jsk4581/anti-claude-kor.git
cp -r anti-claude-kor/skills/* ~/.claude/skills/
```

## 사용

```
/anti-claude-kor:ack 초안.md          # 검사하고 고친 뒤 초안.refined.md 로 저장
/anti-claude-kor:ack 검사만: 초안.md   # 점수와 잡힌 표현만 보고
```

파일 대신 글을 그대로 붙여 넣어도 됩니다. "이 글 AI 티 좀 빼 줘"처럼 말로 부탁해도
스킬이 알아서 뜹니다.

검사 스크립트만 따로 돌리려면 이렇게 합니다.

```bash
python3 skills/anti-claude-kor/scripts/lint.py 글.md
```

코드 블록과 인라인 코드, 인용문은 검사하지 않습니다. 문제 표현을 예시로 보여 줘야
할 때는 거기에 넣으세요.

## 점수 읽는 법

| 점수 | 뜻 |
|---|---|
| 20 미만 | 손댈 필요 없음 |
| 20 이상 40 미만 | 의심스러움 |
| 40 이상 | AI가 쓴 티가 뚜렷함 |

참고로 사람이 쓴 위키백과 문서는 2점 안팎, 클로드가 쓴 마케팅 카피는 87점에서 99점이
나왔습니다. 300자가 안 되는 짧은 글은 점수가 튀니 참고만 하세요.

점수는 AI 말투와 얼마나 닮았는지를 나타냅니다. 사람도 AI 글을 많이 읽으면 같은
말투를 따라 쓰게 되고, 그런 글도 똑같이 점수가 오릅니다. 그러니 남의 글이 AI
작성인지 가리는 데 쓰지 말고, 자기 글을 다듬는 데 쓰세요.

## 무엇을 잡나

네 가지로 나눕니다.

- 구조: `A가 아니라 B` 정의, 항목이 늘 셋인 목록, `다만,` `정확히는,`으로 여는
  문장, `한 줄이면 끝` 식 과장
- 기호와 서식: 가운뎃점(·) 열거, 화살표(→), 이모지 불릿, 굵은 글씨 남발
- 어휘: `자리` `판` `틈` 같은 은유, `진짜` `실제로` 같은 강조, `떠받치다` `조용히
  삼켜지다` `근본 원인은` 같은 번역투, `~로 기능합니다`, `층위` `정체` 같은
  어려운 한자어
- 담화: `결론적으로` `종합하면`으로 닫는 맺음말

전각 대시와 어미 통일, 쉼표 비율은 사람 글에도 흔해서 따로 뺐습니다. 다른 패턴이
이미 넘쳤을 때만 점수에 보탭니다.

전체 목록과 예문, 근거는 [REFERENCE.md](skills/anti-claude-kor/REFERENCE.md)에
있습니다. AI 유행어는 해마다 바뀌어서 목록도 계속 손봐야 합니다. 새로 눈에 띈 표현이
있으면 이슈로 알려 주세요.

## 고치는 쪽도 클로드라서

정제를 하는 것도 결국 같은 모델입니다. 고치면서 같은 버릇을 다시 넣기 쉬워서, 스킬은
고친 글을 다시 검사하고 20점을 넘으면 한 번 더 손봅니다. 그래도 남는 게 있으면 다른
모델에 "기계가 쓴 것 같은 문장을 짚어 달라"고 한 번 더 시켜 보세요.
