# anti-claude-kor

AI가 쓴 한국어 글에서 기계 티 나는 수사 패턴을 찾아내고 걷어내는 Claude Code 스킬.

"~가 아니라 ~입니다" 식의 부정 선행 정의, 전각 대시(U+2014), 가운뎃점(·) 열거,
"~하면 끝" 프레이밍처럼 읽다 보면 출처를 짐작하게 되는 표현들이 있다. 이 스킬은
그런 패턴 15종을 정규식 린터로 세어 슬롭 지수(0~100)를 매기고, 허용치를 넘은
패턴만 골라 평범한 서술로 되돌린다.

핵심 설계는 밀도 제어다. 개별 패턴은 전부 멀쩡한 카피라이팅 기법이므로 표현
자체를 금지하지 않는다. 패턴마다 문서당 허용 횟수를 두고, 넘은 만큼만 벌점을
쌓는다. 잘 쓴 대구 하나는 글을 살린다는 전제로, 목표는 장치가 눈에 띄지 않을
만큼 드문 상태다.

## 설치

skills 폴더의 내용물을 Claude Code 스킬 경로에 복사한다.

```bash
git clone https://github.com/jsk4581/anti-claude-kor.git
cp -r anti-claude-kor/skills/* ~/.claude/skills/
```

특정 프로젝트에서만 쓰려면 `~/.claude/skills` 대신 그 프로젝트의
`.claude/skills`에 넣는다. 새 세션부터 스킬이 등록된다.

## 사용

Claude Code 세션 안에서 호출한다. `/ack`는 `/anti-claude-kor`의 줄임이다.

```
/ack 초안.md            # 검사 후 정제, 초안.refined.md 저장
/ack 검사만: 초안.md    # 슬롭 지수 리포트만
```

파일 경로 대신 글을 붙여 넣어도 된다. 린터는 의존성이 없어서 단독으로도 돈다.

```bash
python3 skills/anti-claude-kor/scripts/lint.py 글.md [--json]
```

## 슬롭 지수 읽는 법

| 지수 | 해석 |
|---|---|
| 20 미만 | 정제 불필요 |
| 20~40 | 의심 구간 |
| 40 이상 | 뚜렷한 AI체 |

참고 측정값: 사람이 쓴 위키백과 문서는 6 안팎, AI가 쓴 마케팅 카피는 87~99가
나왔다. 짧은 글(300자 미만)에서는 밀도 기반 지수의 신뢰도가 낮다.

## 어떤 패턴을 잡나

구조(부정 선행 정의, 변환 프레이밍, 무노력 프레이밍 등), 기호(전각 대시,
가운뎃점, 화살표), 어휘(공간 은유 "자리/판/틈", 진정성 마커 "진짜/실제로",
관용 과장구), 담화(어미 통일 결벽) 네 층위 15종. 전체 목록과 예문은
[REFERENCE.md](skills/anti-claude-kor/REFERENCE.md)에 있다.

대구와 스타카토 리듬은 정규식으로 잡히지 않아서, 정제 단계에서 모델이 육안으로
함께 줄이도록 지침에 포함해 두었다.

## 재작성 검증 루프

정제를 수행하는 것도 결국 같은 모델이라, 고치면서 같은 패턴을 다시 흘려 넣기
쉽다. 그래서 스킬은 재작성본을 반드시 린터로 재검증하고, 지수가 20을 넘으면
남은 항목을 다시 고치게 되어 있다. 린터가 재작성자를 감시하는 구조다.
