# anti-claude-kor: 클로드체 한국어 정제기

한국어 글에서 AI 티 나는 수사 패턴의 **밀도**를 잰 뒤, 허용치를 넘은 패턴만 골라
평범한 서술로 되돌린다. 패턴별 근거와 예문은 [REFERENCE.md](REFERENCE.md).

## 절차

1. **대상 확보**: 파일 경로를 받았으면 그대로 쓰고, 대화에 붙여넣은 글이면 임시
   파일로 저장한다.
2. **린트**:
   ```bash
   python3 scripts/lint.py <파일>
   ```
   슬롭 지수 해석: **20 미만** 정제 불필요(그렇게 보고하고 종료) · 20~40 의심 ·
   40 이상 뚜렷한 AI체. (캘리브레이션: 사람이 쓴 위키백과 문서 ≈ 6, AI 마케팅
   카피 ≈ 87~99.)
3. **표적 재작성**: ▲ 표시된(허용 초과) 패턴만 손댄다. 아래 규칙을 따른다.
4. **재검증**: 재작성본을 다시 린트한다. 20 이상이면 남은 ▲ 항목만 다시 고친다
   (최대 2회, 그 이상은 현재 상태와 남은 항목을 보고하고 멈춘다).
5. **보고**: 전후 지수와 정제본을 제시한다. 입력이 파일이면
   `<이름>.refined.<확장자>`로 저장한다.

사용자가 "검사만" 원하면 2번에서 멈추고 리포트만 보고한다.

## 재작성 규칙

의미·사실·정보량·존댓말 문체는 유지한다. 그 위에서:

- 지적된 각 패턴은 글 전체에서 **최대 1회**만 남기고 나머지는 평범한 서술로 바꾼다.
- "A가 아니라 B" 구문은 부정 없이 B를 직접 서술한다.
- 전각 대시(U+2014)는 없애고 쉼표·마침표·조사로 잇는다.
- 가운뎃점(·) 열거는 쉼표나 '와/과, 및'으로 바꾼다. 문장을 나눠도 된다.
- "~하면 끝", "한 줄이면" 같은 무노력 프레이밍은 담백한 사실 서술로 바꾼다.
- 모든 문장이 펀치라인일 필요 없다. 힘 뺀 평범한 문장을 섞어 리듬을 흐트러뜨린다.
- 새 과장·은유·영어 번역투를 추가하지 않는다. 분량은 원문 ±30% 이내.

## 주의: 재작성자 본인이 오염원이다

이 스킬을 실행하는 모델 자신이 클로드체의 원산지다. 재작성하면서 같은 패턴을
무의식적으로 재주입하기 쉽다. 그래서 4단계 재검증은 생략하면 안 된다. 린트 결과가
곧 자기 교정 장치다.

## 한계

- 대구·교차 대구("위성이 보고, AI가 판단해요")와 2박자 스타카토 리듬은 린터가 못
  잡는다. 재작성 시 REFERENCE.md의 A2·A6 항목을 읽고 육안으로 함께 줄인다.
- 지수는 밀도 기반이라 300자 미만의 짧은 글에서는 신뢰도가 낮다.
